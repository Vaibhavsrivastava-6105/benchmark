# Implementation Plan - LLM Benchmark Lab

An enterprise-grade LLM inference benchmarking and observability platform for comparing runtimes (Ollama, vLLM, llama.cpp, Transformers) side-by-side on latency, throughput, hardware efficiency, structured JSON validation, and answer quality.

---

## Architecture Overview

```mermaid
graph TD
    Client[Next.js Web UI / CLI] -->|REST API / SSE| API[FastAPI Server]
    API -->|Read/Write| DB[(SQLite Database)]
    API -->|Queue Jobs| Worker[Async Job Queue]
    Worker -->|Execute Benchmarks| Engine[Benchmark Engine]
    Engine -->|Query Telemetry| Telemetry[Hardware Telemetry Collector]
    Engine -->|Run Requests| Providers[Provider Adapters]
    Providers -->|Ollama API| Ollama[Ollama Server]
    Providers -->|OpenAI SDK / HTTP| OpenAI[vLLM / llama.cpp / SGLang / OpenAI]
    Providers -->|HuggingFace HF| HF[Transformers local execution]
    Engine -->|Evaluate| Eval[Quality & JSON Evaluator]
    Telemetry -->|Query| HW[psutil & pynvml]
```

---

## User Review Required

> [!IMPORTANT]
> **Mock / Demo Mode**: To ensure the platform can be evaluated immediately without needing GPUs or installing runtimes locally, we will implement a fully functioning **Demo Mode** (`DEMO_MODE=true` in environment). It will simulate benchmark execution, stream real-time hardware telemetry, run evaluations, and generate reports. It is clearly labeled "DEMO DATA" in the UI.
> **Transformers Inference**: Running Hugging Face Transformers directly inside the backend python process can block or load massive weights. We will implement a lightweight mock/sub-process approach for Transformers or use small local models (e.g. Qwen2.5-0.5B) using Hugging Face pipelines, with safe error handling if model weights are not loaded.

## Proposed Changes

### Backend Setup (Python / FastAPI / SQLite)

We will set up the backend in `c:/Users/vaibh/OneDrive/Desktop/llm/backend/`.

#### [NEW] [`backend/app/database.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/database.py)
Provides the SQLAlchemy session management, connection arguments for SQLite concurrency, and model Base.

#### [NEW] [`backend/app/models.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/models.py)
Contains the SQLAlchemy models:
- `Provider`: Config details for runtimes (Ollama, vLLM, llama.cpp, etc.)
- `Model`: Models registered for benchmarking.
- `PromptSuite` & `Prompt`: Built-in and user-defined test prompt suites.
- `BenchmarkConfig`: Configuration template for benchmark runs (temperature, concurrency, repetitions).
- `BenchmarkRun`: Details of individual benchmarking experiments.
- `BenchmarkRequest`: Log of each individual request, TTFT, token counts, and latency.
- `TelemetrySample`: Hardware utilization samples gathered during the run.
- `QualityResult`: Results of parsing, regex evaluation, or LLM-judge grading.
- `Report`: Final summary metrics and recommendation profiles.

#### [NEW] [`backend/app/schemas.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/schemas.py)
Pydantic schemas for request/response validation.

#### [NEW] [`backend/app/providers/base.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/providers/base.py)
Base class `InferenceProvider` detailing the standard interface:
- `health_check(self) -> bool`
- `get_models(self) -> list[str]`
- `generate(self, prompt: str, system_prompt: str, options: dict) -> dict`
- `generate_stream(self, prompt: str, system_prompt: str, options: dict) -> AsyncIterator[dict]`

#### [NEW] [`backend/app/providers/ollama.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/providers/ollama.py)
Ollama-specific adapter. Translates configuration and parses response streams to compute true TTFT.

#### [NEW] [`backend/app/providers/openai_compatible.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/providers/openai_compatible.py)
OpenAI-compatible server adapter sharing logic for **vLLM**, **llama-server (llama.cpp)**, and **SGLang**. Parses chunk streams to record first-token latency (TTFT).

#### [NEW] [`backend/app/providers/transformers.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/providers/transformers.py)
Adapter for local Hugging Face Transformers models. Spawns an isolated subprocess or loads locally if resources allow, with graceful fallbacks.

#### [NEW] [`backend/app/providers/registry.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/providers/registry.py)

#### [NEW] [`backend/app/engine/telemetry.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/engine/telemetry.py)

#### [NEW] [`backend/app/engine/evaluator.py`](file:///c:/Users/vaibh/OneDrive/Desktop/llm/backend/app/engine/evaluator.py)
